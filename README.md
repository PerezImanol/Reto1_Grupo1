# Reto1_Grupo1

Esta aplicacion es una pagina web que sirve para gestionar equipamientos, que usa una estructura de Cliente/Servidor, que se comunican para hacer cambios en la base de datos relacionada.

La parte de cliente contiene las paginas web, y los archivos que comunican con el servidor, mientras que el servidor en si procesa las peticiones del usuario para guardarlos en la base de datos.
Para poder usar la aplicacion, en la carpeta de **Servidor**, y la carpeta de **dao** esta el archivo "ConexionDB.php", que contiene las credenciales para la base de datos.
Hay que modificar los credenciales con la contraseña [PH], y localhost se tiene que cambiar a [PH].
